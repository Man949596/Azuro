# Azuro Website

A responsive React landing page inspired by the provided Azuro reference. Header and footer are separate components, and image spaces are intentionally left blank.

## Run locally

```bash
npm install
npm run dev
```

## Project structure

- `src/components/` — reusable header and footer components
- `src/styles/` — page, header, and footer styles
- `src/assets/images/` — add website images here when ready
- `src/App.jsx` — page sections and editable content

The header dropdowns and FAQ accordion work on desktop and mobile. Subtle entrance animations respect the visitor’s reduced-motion preference.
